# motion: 몸 동작 인식 확인 프로그램

웹캠 앞에서 움직이면 몸 동작을 알아보고, 화면에 동작 이름·속도·지연을 보여 주는 프로그램입니다.
MediaPipe 담당 sunbell이 만들고 있습니다. 계획은 `docs/plan-motion-recognition.md`, 결정 기록은 `docs/decisions.md`에 있습니다.

**이어서 개발할 팀원은 [`docs/handover.md`](../docs/handover.md)(인계 문서)부터 읽어 주세요.** 정확한 환경(파이썬 3.11 등), 지금 하던 일, 남은 일이 정리되어 있습니다.

**지금 단계: 4단계**입니다. 몸 뼈대 위에 동작 판정 결과를 보여 주고, 결과가 잠깐 튀어도 바뀌지 않게 하는 떨림 방지를 더했습니다. 판정하는 동작은 두 팔 들기(ARMS_UP)와 몸 좌우 기울이기(LEAN_LEFT/RIGHT)입니다.

모든 팀원이 **같은 방법**으로 실행합니다: 처음 한 번 `setup`, 그 뒤로는 `run`을 더블클릭하면 됩니다.

## 1. 준비물 (처음 한 번)

| 준비물 | 윈도우 | 맥 |
|---|---|---|
| **파이썬 3.11.9** | <https://www.python.org/downloads/release/python-3119/> 에서 "Windows installer (64-bit)"를 받아 설치. 첫 화면 아래의 "Add python.exe to PATH"에 체크 | 같은 주소에서 "macOS 64-bit universal2 installer"를 받아 설치 |
| **git** | <https://git-scm.com/download/win> 에서 받아 설치 | 터미널에서 `git --version`을 입력. 설치하라는 창이 뜨면 설치 |
| 컴퓨터 조건 | 웹캠 | **Apple 칩(M1 이후)**, **macOS 13 이상**, 웹캠 |

- 파이썬은 꼭 **3.11**이어야 합니다. 팀원 모두 같은 버전으로 맞추기로 했습니다.
- 맥이 인텔 칩이거나 macOS가 13보다 낮으면, 지금 쓰는 부품이 설치되지 않습니다. sunbell에게 알려 주세요.

## 2. 레포 받기 (처음 한 번)

**ZIP으로 내려받지 말고** git으로 받습니다. ZIP으로 받으면 맥이 `.command` 파일 실행을 막습니다.
터미널(윈도우는 PowerShell)에서 아래 세 줄을 차례로 입력합니다.

```
git clone https://github.com/yunsuk1590/Sunjong_please.git
cd Sunjong_please
git switch sunbell/motion
```

이미 받아 두었다면 `Sunjong_please` 폴더에서 `git pull`만 하면 최신 내용이 됩니다.

## 3. 설치 (처음 한 번)

`Sunjong_please/motion` 폴더를 열고 아래 파일을 더블클릭합니다.

- 윈도우: **`setup.bat`**
- 맥: **`setup.command`**

진행 순서는 다음과 같습니다.
1. 가상환경(이 프로그램 전용 부품 설치 공간) 만들기
2. 부품 설치
3. 모델 파일 받기
4. 설치 확인

처음에는 몇 분 걸릴 수 있습니다.
- `[완료] 준비가 끝났습니다`가 나오면 성공입니다.
- `[중단]`이 나오면 그 화면을 캡처해서 sunbell에게 보내 주세요.
- 여러 번 실행해도 괜찮습니다. 이미 된 단계는 건너뜁니다.

## 4. 실행

- 윈도우: **`run.bat`** 더블클릭
- 맥: **`run.command`** 더블클릭
  - 처음 실행할 때 "터미널이 카메라에 접근하려고 합니다"라는 창이 뜨면 **허용**하세요.
  - 허용한 뒤에도 영상이 안 나오면 프로그램을 끄고 다시 실행하세요.

**끄는 방법**: 창에서 `q` 또는 `Esc`, 창 닫기(X), 터미널에서 Ctrl+C. 끄면 터미널에 요약이 찍힙니다.

## 5. 화면 읽는 법

```
CAMERA 30 fps   LOOP 29 fps   LATENCY 25 ms
INFER 18 ms   MODEL full   PERSON 1
640x480 ? MSMF
ARMS: L wrist UP  R elbow UP
LEAN: shoulder +15 deg   torso +4 deg
RAW: ARMS_UP
WAIT arms 0.15/0.25s  lean 0.10/0.15s  lost 0.5s
q: quit
```

- 몸 위에는 회색 뼈대 선과 주황색 관절 점이 그려집니다. 잘 안 보이는 관절(가려진 팔 등)은 그리지 않습니다.
- **화면 아래 큰 글씨**: 떨림을 막은 뒤의 결과(STABLE)입니다. 여러 개면 `ARMS_UP + LEAN_LEFT`처럼 함께 나옵니다. 아무 동작도 없거나 사람이 없으면 회색 `NONE`이 나옵니다.
- **`RAW:` 줄**: 떨림을 막기 전의 원래 결과입니다. 사진 한 장마다 바로 바뀝니다.
- **큰 글씨 위의 색 띠**: 최근 3초 동안 동작마다 RAW(위)와 STABLE(아래)이 켜져 있던 때를 색으로 보여 줍니다. 오른쪽 끝이 지금입니다.
  - 색: 초록 = ARMS_UP, 파랑 = LEAN_LEFT, 주황 = LEAN_RIGHT, 어두운 회색 = 동작 없음
  - RAW 띠가 끊겨도 STABLE 띠가 이어져 있으면 떨림 방지가 제대로 동작한 것입니다.
- **`WAIT` 줄**: 떨림 방지 대기 시간(초)입니다. `arms 0.15/0.25s`는 두 팔 들기가 0.15초 유지돼야 켜지고 0.25초 사라져야 꺼진다는 뜻입니다. `lost`는 사람이 이 시간 넘게 안 보이면 모든 동작을 끈다는 뜻입니다.
  - 기다리는 시간만큼 반응이 늦어집니다(안정성과 빠르기는 맞바꾸는 관계).
- **맨 아래 막대**: 어깨 기울기입니다.
  - 가운데 흰 선이 0도입니다.
  - 노란 선은 켜짐 기준, 회색 선은 꺼짐 기준입니다.
  - 체험자가 왼쪽으로 기울면 점이 왼쪽으로 갑니다(거울 화면 기준). LEAN이 켜지면 점이 초록색이 됩니다.

**동작 판정 기준**(어떤 동작을 무엇을 보고 몇 도·어느 높이로 판정하는지)은 [`docs/gesture-rules.md`](../docs/gesture-rules.md)에 모아 두었습니다.
- `ARMS:` 줄: 각 팔을 손목(wrist)·팔꿈치(elbow) 중 무엇으로 판정했는지(`L`은 화면 왼쪽 팔)
- `LEAN:` 줄: 어깨 기울기(판정에 씀)와 몸통 기울기(`torso`, 비교용)

| 표시 | 뜻 | 좋은 값 |
|---|---|---|
| CAMERA | 카메라에서 1초에 받은 사진 수 | 25 이상 |
| LOOP | 프로그램이 1초에 처리해서 보여 준 사진 수 | CAMERA와 비슷 |
| LATENCY | 처리 지연(ms, 1000분의 1초). 사진을 받은 순간부터 화면에 보여 주기 직전까지 걸린 시간. 카메라·모니터 자체의 지연은 빠져 있음 | 작을수록 좋음. 시작 목표는 100 이하 |
| INFER | LATENCY 중 MediaPipe가 몸을 찾는 데 걸린 시간(ms) | 작을수록 좋음 |
| MODEL | 몸 인식 모델. lite = 가벼움, full = 보통 | |
| PERSON / NO PERSON | 찾은 사람 수 / 아무도 없음 | |
| 셋째 줄 | 카메라가 실제로 준 해상도, 영상 형식(모르면 `?`), 카메라 여는 방식 | |

시작할 때 터미널에 `INFO: Created TensorFlow Lite…`, `W0000 …` 같은 영어 줄이 몇 개 나옵니다. MediaPipe가 내는 정상적인 안내라 무시해도 됩니다.

방이 어두우면 카메라가 스스로 노출을 늘리면서 CAMERA 숫자가 떨어질 수 있습니다. 밝은 곳에서 확인하세요.

끌 때 찍히는 요약의 뜻은 다음과 같습니다.
- "보통": 중간값
- "느린 쪽 5%": 가끔 느려질 때의 값

## 6. 설정을 바꿔서 실행 (선택)

더블클릭 대신 터미널에서 실행하면 설정을 붙일 수 있습니다.

- 윈도우(PowerShell, `motion` 폴더에서): `.\run.bat --backend dshow`
- 맥(터미널, `motion` 폴더에서): `./run.command --res 320x240`

| 설정 | 뜻 | 기본값 |
|---|---|---|
| `--camera 1` | 카메라 번호(여러 대일 때) | 0 |
| `--res 320x240` | 요청할 해상도. 카메라가 지원하지 않으면 다른 값이 나옴 | 640x480 |
| `--backend msmf` / `dshow` / `avfoundation` | 카메라 여는 방식 | 윈도우 msmf(안 열리면 dshow), 맥 avfoundation |
| `--no-mirror` | 좌우 반전하지 않기 | 반전함 |
| `--model lite` | 몸 인식 모델(`full` 보통 / `lite` 가벼움. lite는 빠르지만 가만히 있어도 점이 떨림) | full |
| `--num-poses 4` | 한 번에 찾을 최대 사람 수. 1보다 크면 MediaPipe의 떨림 줄이기가 꺼짐 | 1 |
| `--lean-enter 25` | 기울이기가 켜지는 어깨 각도(도) | 22 |
| `--arms-on 0.1` / `--arms-off 0.2` | 떨림 방지: 두 팔 들기가 켜지려면 유지, 꺼지려면 사라져야 하는 시간(초) | 0.15 / 0.25 |
| `--lean-on 0.05` / `--lean-off 0.1` | 떨림 방지: 기울이기의 같은 시간(초) | 0.10 / 0.15 |
| `--lost 1.0` | 사람이 이 시간(초) 넘게 안 보이면 모든 동작을 끔. 더 짧게 안 보이면 결과를 유지 | 0.5 |
| `--lean-exit 10` | 기울이기가 꺼지는 어깨 각도(도). 켜짐 각도보다 작게 | 7 |

## 8. 파일 설명

| 파일 | 하는 일 |
|---|---|
| `setup.bat` / `setup.command` | 처음 한 번 더블클릭. 파이썬 3.11을 찾아 `setup_env.py`를 실행 |
| `run.bat` / `run.command` | 더블클릭하면 `run.py`를 실행 |
| `setup_env.py` | 가상환경 만들기 → 부품 설치 → 모델 받기 → 설치 확인(윈도우·맥 공통) |
| `run.py` | 실행 파일. 카메라 사진 받기 → 몸 찾기 → 그리기 → 화면에 보여 주기 순서를 정함 |
| `config.py` | 설정값 모음(카메라 번호, 해상도, 카메라 여는 방식, 모델, 사람 수) |
| `pose.py` | MediaPipe로 몸 관절 33개 점을 찾음. 결과는 "사람 목록" |
| `stabilizer.py` | 떨림 방지. 결과가 일정 시간 이어져야 바뀌게 하고, 사람이 오래 안 보이면 모든 동작을 끔 |
| `gestures/` | 동작 규칙 모음. 동작 하나 = 파일 하나(`arms_up.py`, `lean.py`). `base.py`는 공통 틀, `__init__.py`는 동작 목록 |
| `camera.py` | 카메라 담당. 따로 도는 작업 줄이 가장 최근 사진 1장만 들고 있어 지연이 쌓이지 않음 |
| `metrics.py` | 초당 장수와 지연을 재는 도우미 |
| `overlay.py` | 화면 위에 글씨와 몸 뼈대를 그림 |
| `download_models.py` | 구글 공식 저장소에서 몸 인식 모델을 받음(버전 고정, 크기 확인) |
| `requirements.txt` | 설치할 부품 목록(정확한 버전으로 고정) |

**설치 목록에 대한 메모.** `requirements.txt`에는 한글을 쓰지 않습니다. 한국어 윈도우의 설치 도구가 한글을 읽다가 멈추기 때문입니다. 버전을 고른 이유는 여기에 적습니다.
- **MediaPipe 1.0.0**: 최신 1.0.1은 맥에서 몸 인식을 시작하자마자 강제 종료됩니다(공식 이슈 #6356). 고친 버전이 나오면 다시 검토합니다.
- **OpenCV**: `opencv-contrib-python`만 씁니다. `opencv-python`을 같이 설치하면 충돌합니다.

## 9. 새 동작 추가하는 방법

동작 하나는 `gestures` 폴더 안의 파일 하나입니다.

1. `gestures/arms_up.py`를 복사해 새 파일을 만듭니다(예: `squat.py`).
2. 새 파일에서 세 가지를 새 동작에 맞게 고칩니다.
   - `name`: 동작 이름
   - `states`: 나올 수 있는 상태 이름들
   - `check()`: 판정 규칙
3. `gestures/__init__.py`의 `make_gestures()` 목록에 한 줄을 추가합니다.
   - 떨림 방지 시간을 따로 정하려면 `stabilizer.py`의 `make_stabilizer()`에도 한 줄을 추가합니다. 안 하면 기본값(켜짐 0.15초, 꺼짐 0.2초)을 씁니다.
4. 판정 기준을 [`docs/gesture-rules.md`](../docs/gesture-rules.md)에 같은 형식으로 적습니다.

규칙을 쓸 때 알아 둘 것
- 관절 위치는 `frame.point(PoseLandmark.NOSE)`처럼 꺼냅니다. 결과는 픽셀 좌표이고, y는 아래로 갈수록 커집니다.
- 왼쪽·오른쪽은 화면에 보이는 쪽(`frame.shoulders()`가 화면 왼쪽부터 돌려줌)으로 정합니다. MediaPipe의 LEFT/RIGHT 이름은 거울 화면에서 뒤바뀌기 때문입니다.
- `history`에는 최근 약 2초의 사진 정보가 들어 있습니다. 제자리 달리기처럼 반복되는 동작은 이것으로 판정합니다.
- `previous`는 이 동작의 직전 상태입니다. 켜질 때와 꺼질 때 기준을 다르게 둘 때 씁니다.
