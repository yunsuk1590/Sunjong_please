### 첫 할 일 ② 글자를 받아 차를 움직이는 코드 새로 쓰기 (가장 중요, 예시: 11/7까지)

- **보낼 글자 약속 (11/8 sunbell 결정)**: `F` = 앞으로, `S` = 멈춤.
- 글자를 해석하는 부분을 **한곳에 모아** 두면, 약속이 바뀌어도 고치기 쉽습니다.
- **함께 넣을 동작 (11/8 sunbell 결정, [팀 결정 기록](team-decisions.md)의 「11/11 학과 발표회 시연」)**

    - 이렇게 하면 sunbell 노트북 없이도 맥의 시리얼 모니터로 바로 시험할 수 있습니다.
    - 발표회에서 블루투스가 안 될 때 USB 선 예비책도 그대로 준비됩니다.

    - `F`를 받으면 정해진 시간만 앞으로 가고 멈춥니다. 시간은 코드의 상수 하나로 두고, 임시로 1초로 만듭니다. 몇 초로 할지는 sunbell과 의논해서 정합니다.
    - 노트북 프로그램이 멈추거나 사람이 화면 밖으로 나가도, 차가 계속 달려 나가지 않습니다.

  1. USB 선으로 연결하고, 시리얼 모니터에서 글자를 보내 봅니다.
  2. 할 수 있으면 맥에서 HC-06과 짝을 맺고(페어링) 블루투스로도 보내 봅니다. 맥의 「시스템 설정 → Bluetooth」에서 짝을 맺은 뒤, 아두이노 프로그램의 포트 목록에서 `/dev/cu.HC-06…` 같은 이름을 고릅니다.
     - 맥에서 잘 안 되면 넘어가도 됩니다. 발표회는 sunbell 윈도우 노트북으로 합니다. 맥에서 포트가 잘 안 열렸다는 사례가 있습니다(「8. 막히면」의 참고 자료).
- **됐다고 볼 때**: 시리얼 모니터에서 보낸 글자로 차가 약속대로 움직이고 멈춥니다.
- **끝나면**: 코드를 `yunsuk1590/arduino` 브랜치에 올리고(push) sunbell에게 알려 주세요.
- **11/11 상태**: 코드가 올라왔고(`00ef9f2`), 두 사람 모두 차에 올려 시험했습니다. 남은 것은 위 「지금 할 일 (11/11)」에 있습니다.

| git | 맥에 설치 | 깃허브에 올릴 때(push) 비밀번호 대신 토큰(Personal access token)을 넣습니다 |

- **아직 정하지 않은 것**
  - 이음제에서 쓸 **값의 모양** → 안건 「개발 2 · 내보낼 값」
    - 후보: 명령어 방식(예: 「앞으로」 「멈춤」) / 숫자 방식(예: 속도 0~1) / 둘을 섞은 방식
  - 이음제에서 노트북과 아두이노를 **어떻게 이을지** → 안건 「개발 3 · 아두이노 연결 방식」
  - 정해지면 「값 약속 문서」(`docs/value-spec.md`)로 정리합니다.
- 몸 동작 인식 쪽은 원래 「첫 번째 목표」(동작을 제대로 알아보는지 확인)가 끝난 뒤에 값을 내보내는 부분을 만들기로 했습니다. 11/8에 sunbell이 11/11 발표회를 위해 이 부분을 바로 시작하기로 했습니다.

## 6. 브랜치와 커밋

### 처음 한 번: 내 브랜치 만들기 (맥의 「터미널」 앱에서)
팀 문서 PR이 합쳐지기를 기다리지 말고 **바로** 만들어도 됩니다. 아두이노 코드는 `arduino/` 폴더에만 있어서, 나중에 합칠 때 팀 문서와 부딪히지 않습니다.

```
git clone https://github.com/yunsuk1590/Sunjong_please.git
cd Sunjong_please
git switch main
git pull
git switch -c yunsuk1590/arduino
git push -u origin yunsuk1590/arduino
```

- 각 줄이 하는 일: 레포 받기 → 그 폴더로 들어가기 → main으로 가기 → main 최신으로 받기 → 내 브랜치 `yunsuk1590/arduino` 만들기 → 그 브랜치를 깃허브에도 만들기
- 레포를 이미 받아 두었다면 첫 줄은 건너뛰고, 그 폴더에서 `git fetch`를 먼저 합니다.
- 이 맥에서 처음 커밋한다면, 커밋에 남을 이름을 먼저 정합니다.
  - `git config --global user.name "깃허브 아이디"`
  - `git config --global user.email "깃허브에 등록한 이메일"`

### 폴더 구성 (예시)

```
arduino/
  README.md          작업 기록: 설치한 버전, 보드 설정, 글자 약속, 시험 결과, 정한 것
  car/car.ino        차: 글자를 받아 움직이기
  gate/gate.ino      장애물(콘텐츠 2): 부품이 정해지면
```

아두이노 프로그램은 **프로그램 파일 이름과 폴더 이름이 같아야** 합니다(예: `car` 폴더 안의 `car.ino`).

### 작업을 올릴 때

```
git add arduino
git commit -m "arduino - 무엇을 바꿨는지"
git push
```

### main에 합칠 때
- 한 덩어리가 끝나면(예: 「보낸 글자로 차가 움직임」) 깃허브에서 `yunsuk1590/arduino` → `main` PR을 엽니다.
- sunbell이 검토한 뒤 **「Create a merge commit」**(기본 합치기)으로 합칩니다.
- 합친 뒤에도 `yunsuk1590/arduino` 브랜치는 지우지 않습니다. 계속 그 브랜치에서 작업합니다.
- 발표회 준비 중에는 PR을 기다리지 않아도 됩니다. sunbell은 `yunsuk1590/arduino` 브랜치에서 바로 코드를 받아 볼 수 있습니다.

## 7. 지켜 줄 것

- **레포에는 직접 새로 쓴 코드만** 올립니다. 에듀이노 예제 코드(그대로든 고친 것이든), 키트 교육 자료, 라이브러리·드라이버 파일은 올리지 않습니다. 예제는 보고 배우는 데만 씁니다. (이유: [팀 결정 기록](team-decisions.md)의 「키트 교육 자료와 코드 규칙」)
- **main에 직접 올리지 않습니다.** 내 브랜치에서 작업하고 PR로 합칩니다.
- **고치지 않는 것**: 다른 사람의 브랜치(`sunbell/…`), 몸 동작 인식 코드(`motion/` 폴더), 원래 있던 프로그램(`Main.py` 등), 팀 문서(`team-`로 시작하는 문서). 바꿀 것이 있으면 sunbell에게 알려 주세요.
- 무언가를 정하면 `arduino/README.md`에 **날짜, 내용, 이유, 정한 사람**을 적습니다.
- 직접 확인한 것과 짐작을 구분해서 적습니다. AI에게 받은 분석에는 「Claude 분석」처럼 표시합니다.
- 레포가 공개라서 연락처 같은 개인정보는 적지 않습니다.

## 9. 낱말 풀이

| 말 | 뜻 |
|---|---|
| 시연 | 사람들 앞에서 실제로 돌아가는 모습을 보여 주는 것입니다 |
| 기믹 | 게임의 핵심 놀이 장치입니다. 예: 동작으로 여는 차단봉 |
| 통합 | 몸 동작 인식 결과를 아두이노로 보내서 실제로 움직이게, 두 쪽을 잇는 일입니다 |
| HC-06 | 아두이노에 붙이는 블루투스 모듈입니다. 휴대폰이나 노트북과 무선으로 글자를 주고받습니다 |
| 페어링(짝 맺기) | 블루투스 기기끼리 처음 한 번 서로 연결을 허락하는 것입니다 |
| 포트 | 컴퓨터가 보드(또는 블루투스 모듈)와 글자를 주고받는 통로입니다. 아두이노 프로그램의 「포트」 목록에서 고릅니다 |
| 시리얼 모니터 | 아두이노 프로그램 안의 창입니다. 보드와 글자를 주고받을 수 있습니다 |
| 업로드 | 내가 쓴 프로그램을 아두이노 보드에 넣는 것입니다 |
| 라이브러리 | 남이 만들어 둔 코드 묶음입니다. 가져다 쓰면 모터 같은 부품을 쉽게 다룰 수 있습니다 |
| 드라이버 | 컴퓨터가 보드를 알아보게 해 주는 프로그램입니다 |
| 서보모터 | 정해진 각도까지만 돌아가는 작은 모터입니다. 차단봉을 올리고 내리는 데 많이 씁니다 |
| 브랜치 | 레포 안의 내 작업 공간입니다. 내 브랜치에서 작업하면 다른 사람 작업과 부딪히지 않습니다 |
| main | 레포의 기본 브랜치입니다. 깃허브에서 레포를 열면 처음 보이는 곳입니다 |
| 커밋 / push | 커밋: 작업을 한 덩어리로 저장해 기록을 남기는 것. push: 내 컴퓨터의 커밋을 깃허브에 올리는 것 |
| PR(풀 리퀘스트) | 「내 브랜치의 작업을 main에 합쳐도 될까요?」 하고 깃허브에서 요청하는 것입니다. 다른 사람이 보고 합칩니다 |
| 토큰 | 깃허브에 올릴 때 비밀번호 대신 쓰는 긴 암호입니다. 깃허브 설정에서 만듭니다 |
