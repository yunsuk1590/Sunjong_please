## 3. 첫 할 일 (순서대로)

콘텐츠를 어떻게 하든 쓸 수 있는 일부터 합니다. 하나씩 끝날 때마다 `arduino/README.md`에 결과를 적고 sunbell에게 알려 주세요.

### ① 맥에 개발 환경 만들고 업로드 확인
- 아래 4번 「필요한 환경」대로 설치합니다.
- 직접 쓴 짧은 스케치(예: 모터 잠깐 돌리기)를 키트 보드에 올려 봅니다.
- **성공**: 맥에서 업로드가 되고 차가 그대로 움직임.

### ② 맥에서 HC-06으로 명령을 보내 차 움직이기 (가장 중요)
- 지금까지는 스마트폰 앱으로 조종했습니다. 이번에는 **맥이 보낸 글자**로 차가 전진·정지하게 합니다.
- 방법(예): 맥의 블루투스 설정에서 HC-06과 짝을 맺습니다 → 아두이노 프로그램의 포트 목록에서 `/dev/cu.HC-06…` 같은 포트를 고릅니다 → 시리얼 모니터에서 글자를 보냅니다.
- 명령 글자는 **임시로 자유롭게** 정해도 됩니다. 최종 약속은 개발 2(보낼 값)에서 정하므로, 코드에서 **명령을 해석하는 부분을 한곳에 모아** 나중에 바꾸기 쉽게 해 주세요.
- **성공**: 맥에서 보낸 글자로 차가 전진·정지함.
- **함께 적어 줄 것**: 보낸 뒤 반응이 바로 오는지(느낌), 몇 m까지 되는지, 연결이 끊기지 않는지. 이 결과로 개발 3(연결 방식)을 정합니다.
- **안 되면**: 오류 메시지와 해 본 것을 적어 sunbell에게 알려 주세요. 맥에서 HC-06 포트가 잘 안 열린다는 사례가 있습니다(아래 출처). 대안은 윈도우 PC에서 시험하기, 또는 USB 선으로 직접 연결하기입니다.

### ③ 속도 단계 만들기
- 같은 명령 방식으로 **서행 / 보통 / 돌진** 같은 속도 단계를 만듭니다. 타이밍 주행에서 「성공하면 돌진, 실패하면 서행·멈춤」에 쓸 수 있습니다.
- 생각해 둘 것(Claude 의견, 아직 안 정함): 연결이 끊기거나 명령이 한동안 안 오면 차를 **멈추게** 할지. 부스에서 차가 혼자 계속 달리는 사고를 막을 수 있습니다.

### ④ 게이트 부품 확인 (조사만, 사지 않기)
아래를 확인해서 `arduino/README.md`에 적어 주세요. **부품을 사기 전에는 sunbell과 상의**합니다.
- 차단봉을 움직일 서보모터(각도를 맞춰 돌리는 작은 모터)가 있는지, 몇 개인지, 모델명
- 차에 쓰지 않는 아두이노 보드가 있는지. 게이트는 트랙에 따로 놓여서, 차의 보드와 별도 보드가 필요할 수 있습니다.
- 게이트 보드를 노트북과 어떻게 이을 수 있는지(USB 선 / 블루투스 모듈 여분)
- 더 사야 할 것이 있다면 목록

## 5. MediaPipe 쪽과 만나는 지점 (아직 안 정함)

```
웹캠 → [MediaPipe: 동작 판정] → [값 만들기] → [통합: 보내기] → [아두이노: 받아서 움직이기]
        sunbell                  sunbell        담당 미정          yunsuk1590
```

- **정하지 않은 것**
  - 보낼 값의 모양(개발 2): 명령어 방식(예: 전진/정지) / 숫자 방식(예: 속도 0~1) / 섞은 방식
  - 연결 방식(개발 3): 블루투스(HC-06) / USB 선
  - 정해지면 값 명세 문서(`docs/value-spec.md`)로 씁니다.
- **그 전까지 아두이노 쪽이 해 둘 것**: 명령 해석을 한곳에 모아 두기(3-②), 맥에서 HC-06이 되는지와 반응 느낌 알려 주기(개발 3의 자료).
- MediaPipe 쪽은 첫 번째 목표(인식 확인)가 끝난 뒤에 「값을 내보내는 자리」를 만듭니다(정해진 순서).

## 6. 브랜치와 커밋

**시작 (처음 한 번, 맥 터미널)**: 팀 문서 PR이 main에 합쳐진 뒤에 합니다.

```
git clone https://github.com/yunsuk1590/Sunjong_please.git
cd Sunjong_please
git switch main
git pull
git switch -c yunsuk1590/arduino
git push -u origin yunsuk1590/arduino
```

- 레포를 이미 받아 두었다면 첫 줄은 건너뛰고, 그 폴더에서 `git fetch`를 먼저 합니다.
- 이 맥에서 처음 커밋한다면, 커밋에 남을 이름을 먼저 정합니다: `git config --global user.name "깃허브 아이디"`, `git config --global user.email "깃허브에 등록한 이메일"`

**폴더 구성 (예시)**

```
arduino/
  README.md          작업 기록: 환경(버전), 시험 결과, 정한 것
  car/car.ino        차: 명령을 받아 움직이기
  gate/gate.ino      게이트: 만들기로 정해지면
```

아두이노 프로그램은 **스케치 파일 이름과 폴더 이름이 같아야** 합니다(`car/car.ino`).

**작업 → 올리기**

```
git add arduino
git commit -m "arduino - 무엇을 바꿨는지"
git push
```

**main에 합치기**: 한 덩어리가 끝나면(예: 「맥에서 보낸 글자로 차가 움직임」) 깃허브에서 `yunsuk1590/arduino` → `main` PR을 엽니다. sunbell이 검토한 뒤 **「Create a merge commit」**으로 합칩니다. 합친 뒤에도 브랜치는 지우지 않습니다.
