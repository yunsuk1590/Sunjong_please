## 1 · 준비물

| 준비물 | 내용 |
|---|---|
| 윈도우 노트북 | 웹캠이 있어야 합니다. 맥은 아직 시험하지 않았습니다 |
| 파이썬 **3.11** | <https://www.python.org/downloads/release/python-3119/> 에서 「Windows installer (64-bit)」. 설치 첫 화면 아래 「Add python.exe to PATH」에 체크. **3.11이면 3.11.6이어도 됩니다**(설치 프로그램은 3.11인지만 봅니다. test1이 3.11.6으로 잘 돕니다) |
| 전원 어댑터 | 시험과 이음제 때는 꼭 꽂아 둡니다(「5 · 노트북 설정 맞추기」) |
| 인터넷 | 처음 설치할 때 부품과 모델을 받습니다. 노트북 2대를 이을 때는 **두 노트북이 같은 와이파이**여야 합니다 |

파이썬이 깔렸는지 PowerShell에서 확인합니다. `Python 3.11.…`이 나오면 됩니다.

```powershell
py -3.11 --version
```

## 2 · 코드 받기 (처음 한 번)

노트북에 git이 있는지에 따라 둘 중 하나로 합니다.

### 2-1 · git이 있을 때 (my)

```powershell
git clone https://github.com/yunsuk1590/Sunjong_please.git
```
```powershell
cd Sunjong_please
```
```powershell
git switch sunbell/motion
```

### 2-2 · git이 없을 때 (test1, test2)

1. 브라우저에서 아래 주소를 엽니다. 몸 동작 브랜치(`sunbell/motion`)의 ZIP이 바로 받아집니다.
   `https://github.com/yunsuk1590/Sunjong_please/archive/refs/heads/sunbell/motion.zip`
2. 원하는 곳(예: 바탕화면)에 압축을 풉니다. `Sunjong_please-sunbell-motion` 같은 이름의 폴더가 생깁니다.
3. 그 안의 `motion` 폴더가 프로그램 폴더입니다.

- 빌린 노트북에는 git을 깔지 않았습니다(test1). 깔지 말지는 sunbell이 정합니다.

## 3 · 설치 (처음 한 번)

1. `motion` 폴더에서 **`setup.bat`**을 더블클릭합니다.
2. `[1/4]`부터 `[4/4]`까지 차례로 진행합니다(가상환경 만들기 → 부품 설치 → 모델 받기 → 설치 확인). 처음에는 몇 분 걸립니다.
3. **`[완료] 준비가 끝났습니다`**가 나오면 성공입니다.
   - `[중단]`이 나오면 그 화면을 사진으로 찍어 sunbell에게 보냅니다.
   - 여러 번 실행해도 괜찮습니다. 이미 된 단계는 건너뜁니다.
4. 설치가 끝나면 `motion` 폴더 안에 `.venv`(가상환경)와 `models`(모델 파일) 폴더가 생깁니다. **이 두 폴더는 지우지 않습니다.**

## 4 · 코드를 새로 받을 때 (업데이트)

몸 동작 코드가 바뀌면(MediaPipe 세션이 새로 올리면) 노트북마다 새 코드를 받습니다.

| 노트북 | 하는 법 |
|---|---|
| git이 있을 때(my) | `Sunjong_please` 폴더에서 `git pull` |
| ZIP일 때(test1, test2) | 「2-2」처럼 ZIP을 새로 받아, **원래 폴더 위에 덮어씁니다** |

- ZIP에는 `.venv`와 `models`가 들어 있지 않아서, 폴더 통째로 덮어써도 이 두 폴더는 남습니다(11/20 test1에서 확인: 덮어쓴 뒤에도 `run.bat`이 잘 됨).
- 덮어쓴 뒤 `motion` 폴더에 `.venv`와 `models`가 그대로 있는지 봅니다. 없으면 `setup.bat`을 다시 실행합니다.
- 부품 목록(`requirements.txt`)이 바뀐 업데이트라면 `setup.bat`을 한 번 다시 실행합니다. 잘 모르겠으면 그냥 다시 실행해도 됩니다(이미 된 단계는 건너뜀).
- 새로 받은 뒤 「0」의 표에 **받은 날짜**를 적어 두면, 노트북마다 같은 코드인지 헷갈리지 않습니다.

## 6 · 차와 블루투스 짝 맺기 (P1 노트북만)

차에는 블루투스 모듈(HC-06)이 1개뿐이라, **차와 이어지는 것은 P1 노트북 하나**입니다. P2 노트북은 와이파이로 P1에 보냅니다.

| 차 | 블루투스 이름 | 지금 올라간 코드 |
|---|---|---|
| 메인 차(sunbell 차) | `IEUMCAR2` | `car_race`(협동 레이싱용) |
| 예비 차 | 아직 `HC-06`(나중에 `IEUMCAR1`로 바꿈) | 담당자 코드(`car.ino`). 11/23쯤 `car_race`로 맞춤 |

1. 차의 전원을 켭니다.
2. 윈도우 설정에서 블루투스 장치를 추가하고, 차의 블루투스 이름을 골라 짝을 맺습니다.
   - 11/11 my에서는 「장치 추가」로 짝을 맺어도 COM 포트가 생기지 않아서, `DevicePairingWizard`(윈도우에 들어 있는 짝 맺기 창. 실행 창(Win+R)에 입력)로 맺었습니다.
3. 짝을 맺으면 COM 포트가 2개 생깁니다. 「장치 관리자」의 「포트」나 블루투스 설정의 「COM 포트」 목록에서 **「나가는(Outgoing)」 포트**를 찾습니다. 이 번호를 프로그램에 적습니다.
4. 포트 번호는 **노트북마다 다릅니다.** 찾은 번호를 아래 「7」의 표에 적습니다.

- USB 선으로 차와 이을 때는 차 보드의 USB 포트 번호를 씁니다(my에서는 `COM9`).
- 차 보드에 코드를 올리는 법은 [차 코드 README](https://github.com/yunsuk1590/Sunjong_please/blob/sunbell/arduino/arduino/car_race/README.md) 「3」에 있습니다. Arduino IDE가 있는 노트북(my)에서 합니다.

## 8 · 문제가 생기면

| 증상 | 해 볼 것 |
|---|---|
| `파이썬 3.11 을 찾지 못했습니다` | 「1」의 파이썬 3.11을 설치하고, `py -3.11 --version`으로 확인 |
| `카메라를 열지 못했습니다` | 카메라를 쓰는 다른 프로그램을 닫고 다시 실행 |
| 초당 장수(`CAMERA`, `LOOP`)가 20보다 낮음 | 전원을 꽂고 「최고 성능」으로. 방을 밝게 |
| `ERROR - retrying`이 계속 나옴 | 포트가 「나가는」 포트인지, 차 전원이 켜졌는지, 시리얼 모니터 같은 다른 프로그램이 그 포트를 쓰고 있지 않은지 확인 |
| 그 밖의 문제 | 화면을 사진으로 찍어 sunbell에게. 더 많은 경우는 몸 동작 README 「7 · 문제가 생기면」 |

## 9 · 낱말 풀이

| 말 | 뜻 |
|---|---|
| ZIP | 여러 파일을 하나로 묶은 압축 파일. git 없이 깃허브 코드를 받을 때 씁니다 |
| 브랜치 | 같은 저장소 안에서 따로 고치는 줄기. 몸 동작 코드는 `sunbell/motion`, 차 코드는 `sunbell/arduino`에 있습니다 |
| 가상환경(`.venv`) | 이 프로그램 전용 부품 설치 공간. 노트북의 다른 프로그램과 섞이지 않습니다 |
| 모델(`models`) | MediaPipe가 몸을 찾을 때 쓰는 파일 |
| P1 / P2 | 협동 레이싱의 두 역할. P1은 앞뒤(`W`/`S`), P2는 좌우(`A`/`D`) |
| UDP | 같은 와이파이의 두 노트북이 짧은 글자를 빠르게 주고받는 방법 |
| COM 포트 | 노트북이 차 같은 기기와 글자를 주고받는 통로의 번호 |
| 짝 맺기(페어링) | 노트북과 블루투스 모듈이 처음 한 번 서로 연결을 허락하는 것 |
| 나가는(Outgoing) 포트 | 노트북이 블루투스로 글자를 **보낼 때** 여는 COM 포트 |
