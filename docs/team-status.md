## 2. 파트별 상태

### 몸 동작 인식 (MediaPipe)
**담당**: sunbell · **마지막 확인**: 11/5 (`sunbell/motion` 브랜치의 커밋 `4c5d0d3` 기준)

- **하는 일**: 웹캠 영상에서 체험자의 몸 동작(예: 두 팔 들기, 몸 기울이기)을 알아봅니다.
- **지금**: 「첫 번째 목표」(동작을 제대로 알아보는지 화면으로 확인하기)의 5단계 중 **4단계**를 하고 있습니다. 1~3단계는 끝났습니다.
  - 4단계는 「떨림 방지」입니다. 인식 결과가 한순간 튀어도 화면의 결과가 흔들리지 않게 합니다.
- **다음**: 4단계 확인 마무리 → 5단계(속도 다듬기) → 첫 번째 목표 완료 → 「두 번째 목표」(알아본 결과를 다른 프로그램이 받을 수 있는 값으로 내보내기)
- **걸리는 것**: 맥에서는 아직 한 번도 실행해 보지 않았습니다. → 안건 「개발 6 · 팀원 컴퓨터」
- 자세히: [몸 동작 인식 계획서](plan-motion-recognition.md)

### 아두이노
**담당**: yunsuk1590 · **마지막 확인**: 11/5

- **하는 일**: 노트북이 보낸 명령을 받아 차(그리고 만들기로 정하면 차단봉)를 움직이는 아두이노 프로그램과 배선.
- **지금**: 키트 조립과 시험(앞뒤 이동, 스마트폰 앱 조종)은 끝났습니다. 팀 레포에는 아직 아두이노 코드가 없습니다.
- **다음**: [아두이노 담당 작업 안내](arduino-brief.md)의 「3. 첫 할 일」 네 가지
  1. 맥에 아두이노 프로그램 설치
  2. 맥에서 블루투스로 명령을 보내 차 움직이기
  3. 속도 단계(천천히 / 보통 / 빠르게) 만들기
  4. 차단봉에 쓸 부품 조사
- **걸리는 것**
  - 팀 문서를 main에 합치는 PR(합쳐 달라는 요청, sunbell이 만듦)이 합쳐진 뒤에 시작합니다.
  - 콘텐츠가 아직 정해지지 않았습니다. → 안건 「운영 2 · 최종 콘텐츠」

### 통합
**담당**: 아직 정하지 않음 · **마지막 확인**: 11/5

- **하는 일**: 몸 동작 인식 결과를 아두이노로 보내서, 실제로 차나 차단봉이 움직이게 두 쪽을 잇는 일.
- **지금**: 시작 전입니다. 담당도 아직 정하지 않았습니다. sunbell과 yunsuk1590이 함께 할 수도 있습니다. → 안건 「운영 6 · 역할 나누기」
- **다음**
  - 담당 정하기
  - 노트북이 아두이노에 보낼 값의 모양 정하기 → 안건 「개발 2 · 내보낼 값」
  - 노트북과 아두이노를 블루투스로 이을지 USB 선으로 이을지 정하기 → 안건 「개발 3 · 아두이노 연결 방식」
- **걸리는 것**: 몸 동작 인식의 첫 번째 목표가 끝난 뒤에 시작하기로 정해져 있습니다. 콘텐츠도 아직 정해지지 않았습니다.

### 운영 (콘텐츠 · 부스 · 일정)
**담당**: 아직 정하지 않음(안건 정리는 팀장 sunbell) · **마지막 확인**: 11/5

- **하는 일**: 어떤 콘텐츠를 할지, 부스를 어떻게 꾸미고 돌릴지, 일정.
- **지금**
  - 이음제 날짜를 확인했습니다(11/28).
  - 「동시 최대 4인」의 뜻을 확인했습니다. 부스에 동시에 있을 수 있는 인원이고, 정해진 규칙은 아닙니다.
  - 콘텐츠 기획 초안이 있습니다(위 「1. 기본 정보」의 「만들 콘텐츠」).
- **다음**: 콘텐츠를 어떻게 진행할지 정하기 → 일정 세우기
- **걸리는 것**: 안건 「운영 2 · 최종 콘텐츠」, 「운영 3 · 부스 환경」, 「운영 4 · 부스 컴퓨터와 카메라」, 「운영 6 · 역할 나누기」

## 4. 낱말 풀이

| 말 | 뜻 |
|---|---|
| MediaPipe(미디어파이프) | 구글이 만든 도구입니다. 카메라 영상에서 사람 몸의 관절 위치를 찾아 줍니다. 우리는 이것으로 몸 동작을 알아봅니다 |
| 아두이노 | 작은 컴퓨터 보드입니다. 프로그램을 올려서 모터나 센서를 움직입니다. RC카 키트의 두뇌입니다 |
| HC-06 | 아두이노에 붙이는 블루투스 모듈입니다. 휴대폰이나 노트북과 무선으로 글자를 주고받습니다 |
| 통합 | 몸 동작 인식 결과를 아두이노로 보내서 실제로 움직이게, 두 쪽을 잇는 일입니다 |
| 기믹 | 게임의 핵심 놀이 장치입니다. 예: 동작으로 여는 차단봉 |
| 안건 | 아직 정하지 않아서 팀이 함께 정해야 하는 것입니다 |
| 레포(저장소) | 팀의 코드와 문서를 모아 두는 깃허브 공간입니다. 우리 레포는 공개라서 누구나 볼 수 있습니다 |
| 브랜치 | 레포 안의 작업 공간입니다. 각자 자기 브랜치에서 작업하면 서로 부딪히지 않습니다. 예: `sunbell/motion` |
| main | 레포의 기본 브랜치입니다. 깃허브에서 레포를 열면 처음 보이는 곳입니다 |
| PR(풀 리퀘스트) | 「내 브랜치의 작업을 main에 합쳐도 될까요?」 하고 깃허브에서 요청하는 것입니다. 다른 사람이 보고 합칩니다 |
| 커밋 / push | 커밋: 작업을 한 덩어리로 저장해 기록을 남기는 것. push: 내 컴퓨터의 커밋을 깃허브에 올리는 것 |
