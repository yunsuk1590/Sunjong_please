## 2 · 노트북 설정 맞추기

**두 노트북 모두** 합니다.

1. 전원 어댑터를 꽂습니다.
2. 전원 모드를 **「최고 성능」**으로 둡니다(설정 → 시스템 → 전원). 절전 모드에서는 화면이 느려집니다.
3. 화면 꺼짐과 절전 시간을 **「안 함」**으로 둡니다(설정 → 시스템 → 전원 → 화면 및 절전).
4. 카메라를 쓰는 다른 프로그램(줌, 팀즈, 브라우저 화상 회의)을 닫습니다.
5. **두 노트북을 같은 와이파이에 잇습니다.** 부스 와이파이가 안 되면 둘 다 같은 휴대폰 핫스팟에 잇습니다.
6. **블루투스를 아래 표대로 맞춥니다.**

| 노트북 | 블루투스 |
|---|---|
| 노트북1(P1) | **켬** |
| 노트북2(P2) | **끔** |
| 근처 다른 노트북(my, 맥 등) | **끔** |

- 차는 한 번에 노트북 한 대에만 붙습니다. 다른 노트북의 블루투스가 켜져 있으면 그쪽이 차를 먼저 잡아서, 노트북1이 차와 이어지지 않습니다.

**끝나면:** ✅ 두 노트북이 같은 와이파이에 이어져 있고, 블루투스는 노트북1만 켜져 있습니다.

## 3 · 차 켜기

1. 건전지가 모두 끼워졌는지, 새것인지 봅니다.
2. 차 전원을 켭니다.

**끝나면:** ✅ 차의 블루투스 모듈 불빛이 **깜빡입니다.** 아직 노트북과 이어지지 않았다는 뜻이고, 정상입니다.

## 4 · 노트북 주소 확인

두 노트북이 서로를 찾으려면 와이파이 주소가 필요합니다. 와이파이에 다시 이으면 주소가 바뀔 수 있어서 **켤 때마다 확인**합니다.

1. 두 노트북 모두 PowerShell을 엽니다(시작 메뉴 → `PowerShell` 검색).
2. 아래 명령을 붙여 넣고 Enter를 누릅니다.

```powershell
ipconfig
```

3. 「Wi-Fi」 아래의 **「IPv4 주소」** 줄을 봅니다(`10.…` 또는 `192.168.…` 같은 숫자 4묶음).
   - 바로 아래 「기본 게이트웨이」는 **다른 숫자**입니다. 이것을 적으면 연결이 안 됩니다.
4. 두 주소를 아래 빈칸에 연필로 적습니다.

| 노트북 | IPv4 주소 |
|---|---|
| 노트북1 | |
| 노트북2 | |

**끝나면:** ✅ 두 노트북의 주소가 빈칸에 적혀 있습니다.

## 7 · 시험 주행 → 체험자 받기

### 7-1 · 시험 주행 (팀원이 직접)

두 노트북 앞에 한 사람씩 서서 아래 동작을 하나씩 해 봅니다.

| 누가 | 동작 | 차가 이렇게 움직이면 됨 |
|---|---|---|
| 노트북1 앞 | 두 팔 들기 | 앞으로 |
| 노트북1 앞 | T자(팔 양옆으로) | 뒤로 |
| 노트북2 앞 | 왼팔 들기 | 왼쪽으로 돎 |
| 노트북2 앞 | 오른팔 들기 | 오른쪽으로 돎 |
| 둘이 함께 | 두 팔 들기 + 왼팔 들기 | 왼쪽으로 휘며 앞으로(커브) |
| 둘 다 | 팔 내리기 | 곧 섬 |

**끝나면:** ✅ 여섯 가지가 모두 표대로 움직이면 준비 끝입니다.

**안 되면:** → 부록 C-1(차가 안 움직일 때 점검 순서)
- 좌우만 안 되면 노트북1 화면의 `NET` 줄을 봅니다. `recv` 숫자가 늘지 않으면 노트북2의 동작이 오지 않는 것입니다 → 부록 C-2

### 7-2 · 체험자를 받을 때

- **두 프로그램은 켜 둔 채로** 체험자만 바꿉니다. 판마다 다시 켤 필요가 없습니다.
- 체험자는 카메라에 **상반신이 다 보이게** 섭니다. 뒤에 다른 사람이 화면에 들어오지 않게 합니다.
- 시작 전에는 **팔을 내리고** 있게 합니다.
- 한 판 3분, 랩 타임을 잽니다. 벽에 닿아도 그대로 계속합니다. ⚠ 몇 바퀴: (리허설 뒤에 적기. 한 바퀴가 40초보다 짧으면 2바퀴)
- 자리: 화면을 바라보고 **왼쪽이 노트북1(P1 · 앞뒤)**, **오른쪽이 노트북2(P2 · 좌우)**입니다.
- 안내 문구 예: 「왼쪽 분은 앞뒤, 오른쪽 분은 좌우를 맡아요. 두 팔을 들면 앞으로 가요.」

### 7-3 · 끄기

- 카메라 화면 창에서 **`q`**나 **`Esc`**를 누르면 꺼집니다.
- **노트북1(P1)을 끄면 차가 바로 섭니다.** 노트북2(P2)를 끄면 좌우만 멈춥니다.
- 다시 켤 때는 노트북1(5단계) → 노트북2(6단계) 순서로 켭니다. 와이파이가 그대로면 주소는 다시 확인하지 않아도 됩니다.

## 부록 A · 블루투스 다시 잡기

**언제:** 노트북1 프로그램을 켰는데 차 불빛이 계속 깜빡이거나, `OUTPUT` 줄에 `COM3 OPEN`이 안 보일 때.

### A-1 · 먼저 해 볼 것 (짝을 다시 맺지 않고)

1. 노트북1 프로그램을 끕니다(`q`).
2. **근처 다른 노트북(노트북2 포함)의 블루투스가 모두 꺼졌는지** 다시 봅니다. 가장 흔한 원인입니다.
3. 차 전원을 껐다가 켭니다. 건전지가 약하면 새것으로 바꿉니다.
4. 노트북1 프로그램을 다시 켭니다(5단계 3번 명령).

**끝나면:** ✅ 차 불빛이 계속 켜져 있고, `COM3 OPEN`이 보입니다.

**안 되면:** → A-2

### A-2 · 짝을 다시 맺기

짝을 다시 맺으면 **COM 번호가 바뀔 수 있습니다.** 마지막에 새 번호를 확인해 명령에 넣습니다.

1. 노트북1에서 설정 → 블루투스 및 장치 → 장치에서 `IEUMCAR2`를 찾아 **장치 제거**합니다.
2. `Win + R`을 누르고 `DevicePairingWizard`를 입력해 Enter를 누릅니다.
   - 설정의 「장치 추가」 대신 이 창을 씁니다. 「장치 추가」로 맺으면 COM 포트가 안 생길 수 있습니다.
3. 목록에서 `IEUMCAR2`를 선택하고 PIN 번호를 입력합니다.
4. 설정 → 블루투스 및 장치 → 장치 → 「추가 Bluetooth 설정」 → **「COM 포트」** 탭을 엽니다. `IEUMCAR2`의 **「송신(나가는)」** 포트 번호를 봅니다.
   - 저절로 생긴 송신 포트를 씁니다. 「추가」 단추로 직접 만든 포트는 안 됩니다.
5. 5단계 명령에서 `COM3`을 이 번호로 바꿔 켭니다.

**끝나면:** ✅ 차 불빛이 계속 켜져 있고, `COM새번호 OPEN`이 보입니다.

**안 되면:** → 부록 B-5(예비 차로 바꾸기)

### B-1 · 노트북1(P1)이 고장 났을 때 → 노트북2가 P1을 맡음

노트북2도 메인 차와 짝을 맺어 두었습니다(`COM6`).

1. 노트북1의 블루투스를 끄고, 노트북2의 블루투스를 켭니다.
2. 아래 둘 중 하나로 노트북2를 켭니다.

| 방법 | 노트북2 명령 |
|---|---|
| ★ 두 사람(my를 P2로 붙임) | `.\run.bat --port COM6 --role P1 --listen --allow-from my주소` → my는 B-3의 P2 명령으로 켬 |
| 한 사람이 네 동작 모두(커브는 안 됨) | `.\run.bat --port COM6 --letters ARMS_UP=W,T_POSE=S,LEFT_UP=A,RIGHT_UP=D` |

- ⚠ 「두 사람」 방법은 이 조합(노트북2 = P1, my = P2)으로 아직 시험하지 않았습니다.

**끝나면:** ✅ 노트북2 화면에 `COM6 OPEN`이 보이고, 차 불빛이 계속 켜져 있습니다.

### B-2 · 노트북2(P2)가 고장 났을 때

노트북1은 P1 그대로 두고, P2만 바꿉니다.

| 맥을 P2로 붙임 | 위와 같은 방법으로 노트북1을 다시 켭니다(`--allow-from` 자리에 맥 주소). 맥은 B-4 순서로 켭니다 |
| 노트북1 혼자 네 동작(커브는 안 됨) | 노트북1에서 `.\run.bat --port COM3 --letters ARMS_UP=W,T_POSE=S,LEFT_UP=A,RIGHT_UP=D` |

### B-4 · 맥(yunsuk1590)으로 바꿀 때 (P2만)

맥은 **P2로만** 씁니다. P1(차와 연결)로는 시험하지 않았습니다.

1. 맥의 **「터미널」 앱**을 엽니다. 다른 앱(Claude 앱 등) 안의 터미널은 카메라 권한이 안 잡힙니다.
2. `motion` 폴더로 갑니다. ⚠ 맥의 폴더 위치: (리허설 때 확인해 여기에 적기)

4. 길 확인을 한 번 합니다: `.venv/bin/python net_check.py send P1주소`. 와이파이에 막 이은 직후 몇 초는 안 나갈 수 있습니다.
5. 실행합니다: `./run.command --role P2 --send-to P1주소`

**끝나면:** ✅ 맥 화면의 `OUTPUT` 줄에 `UDP … OK`가 보입니다.

### B-5 · 예비 차로 바꿀 때

⚠ **노트북1은 예비 차와 아직 짝을 맺지 않았습니다.** 리허설 때 미리 맺어 두면(부록 A-2 순서, 이름만 `IEUMCAR1`) 아래 「가」로 바로 바꿀 수 있습니다.

**가. 노트북1과 예비 차 짝을 맺어 두었을 때 (★)**
1. 메인 차의 전원을 끕니다.
2. 노트북1 프로그램을 끕니다(`q`).
3. 예비 차를 켭니다.
4. 5단계 명령에서 `COM3`을 예비 차 번호(부록 A-3 표)로 바꿔 켭니다. 노트북2는 그대로 둡니다.

**나. 짝을 맺지 않았을 때 → 두 노트북의 역할을 바꿈**
1. 메인 차와 두 노트북 프로그램을 모두 끕니다.
2. 노트북1 블루투스를 끄고, 노트북2 블루투스를 켭니다.
3. 예비 차를 켭니다.
4. 노트북2를 P1으로 켭니다: `.\run.bat --port COM4 --role P1 --listen --allow-from 노트북1주소`
5. 노트북1을 P2로 켭니다: `.\run.bat --role P2 --send-to 노트북2주소`
6. 앞뒤를 맡는 자리와 좌우를 맡는 자리가 서로 바뀝니다. 체험자에게 다시 안내합니다.

**끝나면:** ✅ 7-1 시험 주행이 모두 됩니다.

### C-2 · 와이파이·연결 문제

노트북2(P2)의 동작은 와이파이로 노트북1에 갑니다. **좌우만 안 될 때**는 대부분 여기입니다.

| 증상 | 할 것 |
|---|---|
| 노트북2 화면 `OUTPUT` 줄이 `NO REPLY` | 아래를 차례로 봅니다. ① 노트북1 프로그램이 켜져 있나 ② 두 노트북이 **같은 와이파이**인가 ③ 명령의 주소가 「IPv4 주소」인가(「기본 게이트웨이」 아님) ④ 노트북1에서 「네트워크 접근 허용」을 눌렀나 |
| 잘 되다가 중간에 `NO REPLY` | 와이파이가 끊겼다 다시 이어지며 **주소가 바뀌었을 수 있습니다.** 두 노트북에서 `ipconfig`로 다시 봅니다(4단계). 바뀌었으면 두 프로그램을 끄고, 새 주소로 노트북1(5단계) → 노트북2(6단계)를 다시 켭니다 |
| 부스 와이파이가 없거나, 로그인 화면이 떠야 하는 와이파이라 안 됨 | **휴대폰 핫스팟**으로 바꿉니다. 두 노트북을 같은 핫스팟에 잇고 4단계부터 다시 합니다 |
| 핫스팟이 저절로 꺼짐 | 핫스팟 휴대폰에 **충전기를 꽂아 두고**, 휴대폰의 「핫스팟 자동 끄기」(연결된 기기가 없으면 끄는 기능)를 끕니다. 휴대폰마다 메뉴 이름이 다릅니다 |
| 와이파이에 막 이은 직후 몇 초 동안 안 됨 | 10초쯤 기다렸다가 다시 봅니다 |
| 노트북1에서 「허용」 창이 안 떴는데 `NO REPLY` | 와이파이가 「공용 네트워크」로 잡혔을 수 있습니다(짐작). 윈도우 방화벽 허용 목록에서 파이썬에 「공용」도 체크합니다 |
