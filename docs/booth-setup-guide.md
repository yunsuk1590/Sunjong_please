## 2 · 노트북 설정 맞추기

**두 노트북 모두** 합니다. (맥은 6-2를 봅니다.)

1. 전원 어댑터를 꽂습니다.
2. 전원 모드를 **「최고 성능」**으로 둡니다(설정 → 시스템 → 전원). 절전 모드에서는 화면이 느려집니다.
3. 화면 꺼짐과 절전 시간을 **「안 함」**으로 둡니다(설정 → 시스템 → 전원 → 화면 및 절전).
4. 카메라를 쓰는 다른 프로그램(줌, 팀즈, 브라우저 화상 회의)을 닫습니다.
5. **두 노트북을 같은 와이파이에 잇습니다.** 부스 와이파이가 안 되면 둘 다 같은 휴대폰 핫스팟에 잇습니다.
6. **블루투스는 P1 노트북만 켜고, 나머지 노트북은 모두 끕니다.** P2 노트북과 근처의 다른 노트북(my, 맥 등)도 끕니다.

- 차는 한 번에 노트북 한 대에만 붙습니다. 다른 노트북의 블루투스가 켜져 있으면 그쪽이 차를 먼저 잡아서, P1 노트북이 차와 이어지지 않습니다.

**끝나면:** ✅ 두 노트북이 같은 와이파이에 이어져 있고, 블루투스는 P1 노트북만 켜져 있습니다.

## 3 · 차 켜기

1. 건전지가 모두 끼워졌는지, 새것인지 봅니다.
2. 차 전원을 켭니다.
3. 차를 트랙 출발점에 놓습니다.

- 두 차 모두 **앞 막힘 기능을 꺼 두었습니다.** 차 앞에 벽이나 물건이 있어도 **차가 스스로 서지 않습니다.** 멈추려면 팔을 내리거나 P1 프로그램을 끕니다.

**끝나면:** ✅ 차의 블루투스 모듈 불빛이 **깜빡입니다.** 아직 노트북과 이어지지 않았다는 뜻이고, 정상입니다.

## 4 · 노트북 주소 확인

두 노트북이 서로를 찾으려면 와이파이 주소가 필요합니다. 와이파이에 다시 이으면 주소가 바뀔 수 있어서 **켤 때마다 확인**합니다.

1. 두 노트북 모두 PowerShell을 엽니다(시작 메뉴 → `PowerShell` 검색).
2. 아래 명령을 붙여 넣고 Enter를 누릅니다.

```powershell
ipconfig
```

3. 「Wi-Fi」 아래의 **「IPv4 주소」** 줄을 봅니다(`10.…` 또는 `192.168.…` 같은 숫자 4묶음).
   - 바로 아래 「기본 게이트웨이」는 **다른 숫자**입니다. 이것을 적으면 연결이 안 됩니다.
   - 맥은 터미널에서 `ipconfig getifaddr en0`으로 봅니다.
4. 두 주소를 아래 빈칸에 연필로 적습니다.

| 역할 | 노트북 | IPv4 주소 |
|---|---|---|
| P1 | | |
| P2 | | |

**끝나면:** ✅ 두 노트북의 주소가 빈칸에 적혀 있습니다.

## 5 · P1 프로그램 켜기 (P1 노트북에서)

어느 노트북이 P1을 맡든 같은 순서입니다.

1. 0-3 표에서 이 노트북의 `motion` 폴더를 엽니다.
2. 폴더 창 위쪽의 주소 칸을 클릭하고, 글자를 지운 뒤 `powershell`을 치고 Enter를 누릅니다. 그 폴더에서 PowerShell이 열립니다.
3. 아래 명령을 붙여 넣고, 두 자리를 바꾼 뒤 Enter를 누릅니다.
   - `차COM` → 0-3 표에서 **이 노트북 + 지금 쓰는 차**의 COM 번호(예: 노트북1과 메인 차면 `COM3`)
   - `P2주소` → 4단계에서 적은 P2 노트북 주소

```powershell
.\run.bat --port 차COM --role P1 --listen --allow-from P2주소
```

   (웹캠을 쓰는 경우) 웹캠을 켜기 전에 꽂고, 아래 명령을 씁니다. `웹캠번호`는 0-3 표에서 찾습니다. 켜질 때까지 10초쯤 걸립니다.

```powershell
.\run.bat --port 차COM --role P1 --listen --allow-from P2주소 --camera 웹캠번호
```

4. 「네트워크 접근을 허용할까요?」 창이 뜨면 **허용**을 누릅니다(처음 켤 때만 뜹니다).

**끝나면:** (몇 초 걸립니다)
- ✅ 카메라 화면 창이 뜨고, 화면의 `OUTPUT` 줄에 **`COM번호 OPEN`**이 보입니다.
- ✅ 차의 블루투스 불빛이 깜빡임을 멈추고 **계속 켜져 있습니다.**

**안 되면:** 불빛이 계속 깜빡이거나 `OPEN`이 안 보이면 → 부록 A(블루투스 다시 잡기)

## 7 · 시험 주행 → 체험자 받기

### 7-1 · 시험 주행 (팀원이 직접)

두 노트북 앞에 한 사람씩 서서 아래 동작을 하나씩 해 봅니다.

| 누가 | 동작 | 차가 이렇게 움직이면 됨 |
|---|---|---|
| P1 앞(왼쪽) | 두 팔 들기 | 앞으로 |
| P1 앞(왼쪽) | T자(팔 양옆으로) | 뒤로 |
| P2 앞(오른쪽) | 왼팔 들기 | 왼쪽으로 돎 |
| P2 앞(오른쪽) | 오른팔 들기 | 오른쪽으로 돎 |
| 둘이 함께 | P1 두 팔 들기 + P2 왼팔 들기 | 왼쪽으로 휘며 앞으로(커브) |
| 둘 다 | 팔 내리기 | 곧 섬 |

**끝나면:** ✅ 여섯 가지가 모두 표대로 움직이면 준비 끝입니다.

**안 되면:** → 부록 C-1(차가 안 움직일 때 점검 순서)
- 좌우만 안 되면 P1 화면의 `NET` 줄을 봅니다. `recv` 숫자가 늘지 않으면 P2의 동작이 오지 않는 것입니다 → 부록 C-2

### 7-2 · 체험자를 받을 때

- **두 프로그램은 켜 둔 채로** 체험자만 바꿉니다. 판마다 다시 켤 필요가 없습니다.
- 체험자는 카메라에 **상반신이 다 보이게** 섭니다. 뒤에 다른 사람이 화면에 들어오지 않게 합니다.
- 시작 전에는 **팔을 내리고** 있게 합니다.
- 한 판 3분, 랩 타임을 잽니다. 벽에 닿아도 그대로 계속합니다. ⚠ 몇 바퀴: (리허설 뒤에 적기. 한 바퀴가 40초보다 짧으면 2바퀴)
- 자리: 화면을 바라보고 **왼쪽이 P1(앞뒤)**, **오른쪽이 P2(좌우)**입니다.
- 두 체험자 사이를 조금 띄워, **옆 사람이 내 카메라 화면에 들어오지 않게** 합니다.
- 안내 문구 예: 「왼쪽 분은 두 팔을 들면 앞, T자를 하면 뒤로 가요. 오른쪽 분은 왼팔을 들면 왼쪽, 오른팔을 들면 오른쪽으로 돌아요. 팔을 내리면 서요.」

### 7-3 · 끄기

- 카메라 화면 창에서 **`q`**나 **`Esc`**를 누르면 꺼집니다.
- **P1을 끄면 차가 바로 섭니다.** P2를 끄면 좌우만 멈춥니다.
- 다시 켤 때는 P1(5단계) → P2(6단계) 순서로 켭니다. 와이파이가 그대로면 주소는 다시 확인하지 않아도 됩니다.

## 부록 A · 블루투스 다시 잡기

**언제:** P1 프로그램을 켰는데 차 불빛이 계속 깜빡이거나, `OUTPUT` 줄에 `COM번호 OPEN`이 안 보일 때. 아래는 모두 **P1 노트북**에서 합니다.

### A-1 · 먼저 해 볼 것 (짝을 다시 맺지 않고)

1. P1 프로그램을 끕니다(`q`).
2. **근처 다른 노트북(P2 노트북 포함)의 블루투스가 모두 꺼졌는지** 다시 봅니다. 가장 흔한 원인입니다.
3. 차 전원을 껐다가 켭니다. 건전지가 약하면 새것으로 바꿉니다.
4. P1 프로그램을 다시 켭니다(5단계 3번 명령).

**끝나면:** ✅ 차 불빛이 계속 켜져 있고, `COM번호 OPEN`이 보입니다.

**안 되면:** → A-2

### A-2 · 짝을 다시 맺기

짝을 다시 맺으면 **COM 번호가 바뀔 수 있습니다.** 마지막에 새 번호를 확인해 명령에 넣습니다. 아래 `차이름`은 메인 차면 `IEUMCAR2`, 예비 차면 `IEUMCAR1`입니다.

1. P1 노트북에서 설정 → 블루투스 및 장치 → 장치에서 `차이름`을 찾아 **장치 제거**합니다.
2. `Win + R`을 누르고 `DevicePairingWizard`를 입력해 Enter를 누릅니다.
   - 설정의 「장치 추가」 대신 이 창을 씁니다. 「장치 추가」로 맺으면 COM 포트가 안 생길 수 있습니다.
3. 목록에서 `차이름`을 선택하고 PIN 번호를 입력합니다.
4. 설정 → 블루투스 및 장치 → 장치 → 「추가 Bluetooth 설정」 → **「COM 포트」** 탭을 엽니다. `차이름`의 **「송신(나가는)」** 포트 번호를 봅니다.
   - 저절로 생긴 송신 포트를 씁니다. 「추가」 단추로 직접 만든 포트는 안 됩니다.
5. 5단계 명령의 `차COM` 자리에 이 번호를 넣어 켭니다.
6. 바뀐 번호는 0-3 표에 **연필로 고쳐 적습니다**.

**끝나면:** ✅ 차 불빛이 계속 켜져 있고, `COM새번호 OPEN`이 보입니다.

**안 되면:** → 부록 B(차 바꾸기)

## 부록 B · 노트북이나 차를 바꿀 때

경우마다 따로 외우지 않고, 아래 규칙만 따릅니다.

| 이런 경우 | 이렇게 |
|---|---|
| **노트북이 고장 남** | 다른 노트북이 그 역할을 맡습니다. P1이면 2단계(블루투스)·5단계를, P2면 6단계를 그 노트북에서 다시 합니다. 0-3 표에서 그 노트북의 폴더와 COM 번호를 찾습니다 |
| **P1 노트북이 바뀜** | P2도 **다시 켭니다.** P2가 보낼 주소(`P1주소`)가 바뀌기 때문입니다. 새 P1 노트북 주소는 4단계 방법으로 봅니다 |
| **P2 노트북이 바뀜** | P1을 끄고, `P2주소` 자리에 새 P2 노트북 주소를 넣어 다시 켭니다. 그다음 새 P2 노트북을 켭니다 |
| **메인 차가 고장 남** | 메인 차를 끄고 예비 차를 켭니다. P1을 끄고, `차COM` 자리를 **예비 차 번호**(0-3 표)로 바꿔 다시 켭니다. P2는 그대로 둡니다 |
| 예비 차 번호가 ⚠(짝 없음)인 노트북이 P1일 때 | 예비 차와 짝이 있는 노트북(예: 노트북2)이 P1을 맡게 역할을 바꿉니다(첫 줄 규칙). 시간이 있으면 부록 A-2로 짝을 맺어도 됩니다 |
| **노트북이 한 대만 남음** | 한 사람이 네 동작을 모두 합니다(커브는 안 됨): `.\run.bat --port 차COM --letters ARMS_UP=W,T_POSE=S,LEFT_UP=A,RIGHT_UP=D` |

- 역할을 바꿔도 **P1 노트북은 왼쪽, P2 노트북은 오른쪽**에 둡니다(0-1).
- 바꾼 뒤에는 7-1 시험 주행을 다시 합니다.
- ⚠ 함께 시험한 조합은 「노트북1 = P1 + 노트북2 = P2」(11/27)뿐입니다. my는 P1·P2를 각각 시험했습니다. 다른 조합은 7-1로 꼭 확인합니다.
- 맥은 P2만 맡습니다. P1(차와 연결)로는 시험하지 않았습니다.
- 예비 차는 **우회전 커브가 조금 약합니다**.

## 부록 C · 문제가 생겼을 때

당황하면 **C-1을 위에서부터 순서대로** 봅니다. 원인을 알면 C-2, C-3 표에서 바로 찾습니다. 부스 운영(줄, 안내)은 이 문서에서 다루지 않습니다.

### C-1 · 차가 안 움직일 때 점검 순서

| 순서 | 볼 것 | 이러면 | 이렇게 |
|---|---|---|---|
| 1 | **어느 움직임이 안 되나** | 좌우만 안 되고 앞뒤는 됨 | P2 → P1 와이파이 문제입니다 → **C-2** |
| | | 앞으로만 안 가고 뒤·좌우는 됨 | 앞 막힘을 꺼 두었으니 원래는 생기지 않습니다. 차를 뒤로 빼서 다시 보고, 계속 그러면 예비 차로 바꿉니다(부록 B) |
| | | 다 안 됨 | 2번으로 |
| 2 | **노트북 화면 아래 큰 글씨**가 동작대로 바뀌나(`ARMS_UP`, `T_POSE`, `LEFT_UP`, `RIGHT_UP`) | 안 바뀜(`NONE` 그대로) | 카메라에 상반신이 다 보이게 섭니다. 너무 가깝거나 어두우면 잘 안 잡힙니다 |
| | | 바뀜 | 3번으로 |
| 3 | P1 화면 **`OUTPUT` 줄이 `COM번호 OPEN`**인가 | 아님 | 부록 A |
| | | 맞음 | 4번으로 |
| 4 | **차의 블루투스 불빛** | 계속 깜빡임 | 다른 노트북 블루투스를 끄고 부록 A |
| | | 계속 켜져 있음 | **건전지를 새것으로** 바꿉니다. 불은 켜져도 힘이 없어 안 움직일 수 있습니다 |
| 5 | 그래도 안 됨 | — | P1 프로그램을 끄고(`q`), 차를 껐다 켠 뒤 P1(5단계) → P2(6단계) 순서로 다시 켭니다 |
| 6 | 그래도 안 됨 | — | 예비 차로 바꿉니다(부록 B). 그 사이 sunbell에게 알립니다 |

### C-2 · 와이파이·연결 문제

P2의 동작은 와이파이로 P1 노트북에 갑니다. **좌우만 안 될 때**는 대부분 여기입니다.

| 증상 | 할 것 |
|---|---|
| P2 화면 `OUTPUT` 줄이 `NO REPLY` | 아래를 차례로 봅니다. ① P1 프로그램이 켜져 있나 ② 두 노트북이 **같은 와이파이**인가 ③ 명령의 주소가 「IPv4 주소」인가(「기본 게이트웨이」 아님) ④ P1 노트북에서 「네트워크 접근 허용」을 눌렀나 |
| 잘 되다가 중간에 `NO REPLY` | 와이파이가 끊겼다 다시 이어지며 **주소가 바뀌었을 수 있습니다.** 두 노트북에서 `ipconfig`로 다시 봅니다(4단계). 바뀌었으면 두 프로그램을 끄고, 새 주소로 P1(5단계) → P2(6단계)를 다시 켭니다 |
| 부스 와이파이가 없거나, 로그인 화면이 떠야 하는 와이파이라 안 됨 | **휴대폰 핫스팟**으로 바꿉니다. 두 노트북을 같은 핫스팟에 잇고 4단계부터 다시 합니다 |
| 핫스팟이 저절로 꺼짐 | 핫스팟 휴대폰에 **충전기를 꽂아 두고**, 휴대폰의 「핫스팟 자동 끄기」(연결된 기기가 없으면 끄는 기능)를 끕니다. 휴대폰마다 메뉴 이름이 다릅니다 |
| 와이파이에 막 이은 직후 몇 초 동안 안 됨 | 10초쯤 기다렸다가 다시 봅니다 |
| P1 노트북에서 「허용」 창이 안 떴는데 `NO REPLY` | 와이파이가 「공용 네트워크」로 잡혔을 수 있습니다(짐작). 윈도우 방화벽 허용 목록에서 파이썬에 「공용」도 체크합니다 |

### C-3 · 그 밖의 문제

| 증상 | 할 것 |
|---|---|
| 달리다가 갑자기 안 움직임(화면에는 동작이 잡힘) | 건전지를 새것으로 바꾸고 P1 프로그램을 다시 켭니다 |
| `카메라를 열지 못했습니다` | 카메라를 쓰는 다른 프로그램을 닫고 다시 켭니다. USB 웹캠이면 꽂혀 있는지, `--camera` 번호가 0-3 표와 맞는지 봅니다 |
| 화면이 느림(`CAMERA` 숫자가 20보다 낮음) | 전원 어댑터를 꽂고, 전원 모드를 「최고 성능」으로 둡니다(2단계). 부스가 어두우면 조명을 켭니다 |

## 낱말 풀이

| 말 | 뜻 |
|---|---|
| P1 / P2 | 협동 조작의 두 역할. P1은 앞뒤를 맡고 차와 블루투스로 이어지며, P2는 좌우를 맡고 와이파이로 P1에 보냅니다 |
| P1 노트북 / P2 노트북 | 지금 그 역할을 맡은 노트북. 기본은 노트북1이 P1, 노트북2가 P2입니다 |
| PowerShell | 윈도우에서 글자 명령을 쳐서 프로그램을 실행하는 파란 창 |
| `motion` 폴더 | 몸 동작 프로그램(`run.bat`)이 들어 있는 폴더. 노트북마다 위치가 다릅니다(0-3 표) |
| COM 포트(`COM6` 등) | 노트북이 차와 글자를 주고받는 통로의 번호. 노트북마다, 차마다, 짝을 맺을 때마다 다릅니다 |
| 송신(나가는) 포트 | 블루투스 짝을 맺으면 생기는 COM 포트 2개 가운데, 노트북이 글자를 **보낼 때** 쓰는 것 |
| 짝 맺기(페어링) | 노트북과 차의 블루투스 모듈이 처음 한 번 서로 연결을 허락하는 것 |
| IPv4 주소 | 와이파이 안에서 이 노트북을 찾는 번호. `ipconfig`로 봅니다 |
| 핫스팟 | 휴대폰이 만드는 작은 와이파이 |
| 앞 막힘 | 차 앞 약 20 cm 안에 평평한 물건이 있으면 앞으로 안 가는 기능. 이음제에서는 끕니다 |
