# 협동 조작 모드 세팅 가이드(기본)

> **이 문서는?** 이음제(11/28) 당일, 노트북 2대와 차 1대를 **체험자가 오자마자 바로 조작할 수 있는 상태**로 맞추는 순서를 처음부터 끝까지 적은 안내입니다. Claude에게 묻지 않고 이 문서만 보고 따라 할 수 있게 썼습니다.
> - **누가 읽나요?** 부스를 맡는 팀원 누구나. 팀장 sunbell.
> - **작성**: 2026-11-26, sunbell(Claude 도움). sunbell과 함께 고쳐 가는 중인 **초안**입니다. ⚠ 표시는 아직 정하지 않았거나 시험하지 않은 것입니다.
> - **본문(「0」~「7」)**은 모든 것이 잘 될 때의 기본 순서만 다룹니다. 블루투스 다시 잡기, 다른 노트북으로 바꾸기, 문제가 생겼을 때는 맨 뒤 **부록**에 있습니다.
> - 노트북에 프로그램을 처음 까는 법은 [노트북 세팅 안내](laptop-setup.md)에 있습니다. 이 문서는 **이미 깔려 있다**고 보고 씁니다(노트북1·노트북2 모두 11/23까지 설치 끝).
> - **공개 레포입니다.** IP 주소, 블루투스 모듈 주소, PIN, 실명은 이 문서에 적지 않습니다. 명령에 들어가는 주소는 `노트북1주소`처럼 비워 둡니다.
> - 처음 보는 말은 맨 아래 「낱말 풀이」에 있습니다.

## 0 · 한눈에 보기

### 0-1 · 누가 무엇을 맡나

| 이름 | 실제 노트북 | 역할 | 체험자 동작 | 차와 연결 |
|---|---|---|---|---|
| **노트북1** | test1 | **P1** · 앞뒤 | 두 팔 들기 = 앞, T자 = 뒤 | **블루투스로 차와 직접 연결**(메인 차 `COM3`) |
| **노트북2** | test2 | **P2** · 좌우 | 왼팔 들기 = 왼쪽, 오른팔 들기 = 오른쪽 | 차와 연결하지 않음. 와이파이로 노트북1에 보냄 |

- 헷갈리지 않게 **노트북1 = P1, 노트북2 = P2**로 맞춥니다(2026-11-26 sunbell 결정: 「안헷갈리게 1번이 p1. 2번이 p2 이렇게 가자」).
- 차에는 블루투스 모듈이 1개뿐이라, **차와 이어지는 노트북은 P1(노트북1) 하나**입니다. P2(노트북2)의 동작은 노트북1을 거쳐 차로 갑니다.
- ⚠ **아직 시험 안 함**: 노트북1(test1) = P1, 노트북2(test2) = P2 조합은 아직 해 보지 않았습니다. 지금까지는 반대 조합(test2 = P1, test1 = P2)을 예비 차로 통과했고(11/24), test1은 혼자 메인 차를 몰아 보았습니다(11/25, `COM3`). **리허설 때 이 순서대로 한 번 해 봅니다.**

## 1 · 준비물

- [ ] 노트북1, 노트북2와 **전원 어댑터 2개**(꼭 꽂아 둡니다)
- [ ] 메인 차(`IEUMCAR2`)와 예비 차(`IEUMCAR1`)
- [ ] **새 AA 건전지**와 여분. 약한 건전지는 블루투스 끊김과 「불은 켜졌는데 안 움직임」을 일으킵니다(11/24 확인)
- [ ] 휴대폰 핫스팟(부스 와이파이가 안 될 때 두 노트북을 잇는 데 씀)과 **휴대폰 충전기**
- [ ] 멀티탭
- [ ] ⚠ 큰 모니터와 선(쓸지 정하지 않음)

## 2 · 두 노트북 켜고 설정 맞추기

**두 노트북 모두** 합니다.

1. 전원 어댑터를 꽂습니다.
2. 전원 모드를 **「최고 성능」**으로 둡니다(설정 → 시스템 → 전원). 절전 모드에서는 화면이 초당 18장쯤으로 느려집니다.
3. 화면 꺼짐과 절전 시간을 **「안 함」**으로 둡니다(설정 → 시스템 → 전원 → 화면 및 절전).
4. 카메라를 쓰는 다른 프로그램(줌, 팀즈, 브라우저 화상 회의)을 닫습니다.
5. **두 노트북을 같은 와이파이에 잇습니다.** 부스 와이파이가 안 되면 같은 휴대폰 핫스팟에 둘 다 잇습니다(11/24 핫스팟으로 통과).
6. **블루투스를 맞춥니다.**
   - 노트북1(P1): 블루투스 **켬**
   - 노트북2(P2): 블루투스 **끔**(노트북2도 차와 짝을 맺어 두어서, 켜 두면 차를 먼저 잡을 수 있습니다)
   - 근처의 다른 노트북(my, 맥 등): 블루투스 **끔**
   - 차는 한 번에 노트북 한 대에만 붙습니다. 다른 노트북이 먼저 붙으면 노트북1이 차와 이어지지 않습니다(11/24에 test1이 이 때문에 안 됐고, 11/25 다른 노트북 블루투스를 끄니 됨).

## 3 · 차 켜기

1. 건전지가 모두 끼워졌는지, 새것인지 봅니다.
2. 차 전원을 켭니다. 차의 블루투스 모듈 불빛이 **깜빡이면** 아직 노트북과 이어지지 않은 상태입니다(정상).
3. 차를 트랙 출발점에 놓습니다.

- 이음제에서는 **앞 막힘 기능을 꺼 둡니다**(2026-11-26 sunbell 결정: 「앞 막힘 기능은 꺼 두는 걸로」). 앞에 벽이나 물건이 있어도 차가 멈추지 않습니다.
- **두 차 모두 반영됨**(11/26, 커밋 `ad268b5`, my에서 USB로 올림). 차를 켰을 때 로그 첫 줄이 「앞 막힘 기능: 꺼짐 (거리만 재서 로그로 남김)」입니다. **차가 벽 앞에서 스스로 서지 않으니**, 멈추려면 팔을 내리거나 노트북1 프로그램을 끕니다.

## 4 · 노트북 주소 확인

두 노트북이 서로를 찾으려면 와이파이 주소가 필요합니다. 주소는 와이파이에 다시 이을 때마다 바뀔 수 있어서 **켤 때마다 확인**합니다.

1. 두 노트북 모두 PowerShell을 엽니다(시작 메뉴 → `PowerShell` 검색).
2. 아래 명령을 붙여 넣고 Enter를 누릅니다.

```powershell
ipconfig
```

3. 「Wi-Fi」 아래의 **「IPv4 주소」** 줄을 봅니다(`10.…` 또는 `192.168.…` 같은 숫자 4묶음).
   - 바로 아래 「기본 게이트웨이」는 **다른 숫자**입니다. 이것을 적으면 연결이 안 됩니다(11/23에 겪음).
4. 두 주소를 종이에 적어 둡니다(이 문서에는 적지 않습니다).

## 5 · 노트북1(P1) 프로그램 켜기

1. 노트북1에서 `motion` 폴더를 엽니다. ⚠ 폴더 위치: `바탕화면\…\motion`(실제 위치를 확인해 여기에 적기)
2. 폴더 창의 주소 칸을 클릭하고, 글자를 지운 뒤 `powershell`을 치고 Enter를 누릅니다. 그 폴더에서 PowerShell이 열립니다.
3. 아래 명령에서 `노트북2주소`만 「4」에서 적은 노트북2의 주소로 바꿔 붙여 넣고 Enter를 누릅니다.

```powershell
.\run.bat --port COM3 --role P1 --listen --allow-from 노트북2주소
```

4. 처음 켤 때 「네트워크 접근을 허용할까요?」 창이 뜨면 **허용**을 누릅니다.
5. 카메라 화면 창이 뜹니다. 다음을 확인합니다.
   - 화면의 `OUTPUT` 줄이 **`COM3 OPEN`**이 됩니다. 몇 초 걸립니다.
   - 차의 블루투스 불빛이 **깜빡임을 멈추고 계속 켜집니다.** 이어졌다는 뜻입니다.

- `COM3`은 노트북1과 **메인 차**의 번호입니다. 예비 차는 노트북1과 아직 짝을 맺지 않았습니다(부록 B-4).
- 불빛이 계속 깜빡이면 부록 A(블루투스 다시 잡기)로 갑니다.

## 6 · 노트북2(P2) 프로그램 켜기

1. 노트북2에서 「5」의 1~2번처럼 `motion` 폴더에서 PowerShell을 엽니다. ⚠ 폴더 위치 확인
2. 아래 명령에서 `노트북1주소`만 노트북1의 주소로 바꿔 붙여 넣고 Enter를 누릅니다.

```powershell
.\run.bat --role P2 --send-to 노트북1주소
```

3. 화면의 `OUTPUT` 줄이 **`UDP … OK`**(뒤에 `16ms` 같은 숫자)가 되면 노트북1과 이어진 것입니다.
   - `NO REPLY`면 노트북1이 받지 못하는 것입니다. 주소, 같은 와이파이인지, 노트북1에서 「허용」을 눌렀는지 봅니다.

## 7 · 시작 전 시험 주행 → 체험자 받기

### 7-1 · 시험 주행 (팀원이 직접)

두 노트북 앞에 한 사람씩 서서 하나씩 해 봅니다.

| 누가 | 동작 | 차가 이렇게 움직이면 됨 |
|---|---|---|
| 노트북1 앞 | 두 팔 들기 | 앞으로 |
| 노트북1 앞 | T자(팔 양옆으로) | 뒤로 |
| 노트북2 앞 | 왼팔 들기 | 왼쪽으로 돎 |
| 노트북2 앞 | 오른팔 들기 | 오른쪽으로 돎 |
| 둘이 함께 | 두 팔 들기 + 왼팔 들기 | 왼쪽으로 휘며 앞으로(커브) |
| 둘 다 | 팔 내리기 | 곧 섬 |

- 다섯 가지가 다 되면 준비 끝입니다.
- 노트북1의 `NET` 줄에서 `recv` 숫자가 늘어나는지도 봅니다. 노트북2의 동작이 오고 있다는 뜻입니다.

### 7-2 · 체험자를 받을 때

- **두 프로그램은 켜 둔 채로** 체험자만 바꿉니다. 판마다 다시 켤 필요가 없습니다.
- 체험자는 카메라에 **상반신이 다 보이게** 섭니다. 뒤에 다른 사람이 화면에 들어오지 않게 합니다.
- 시작 전에는 **팔을 내리고** 있게 합니다.
- 한 판 3분, 랩 타임을 잽니다. 벽에 닿아도 그대로 계속합니다. ⚠ 몇 바퀴로 할지는 리허설 뒤에 정함(한 바퀴가 40초보다 짧으면 2바퀴).
- 안내 문구 예: 「왼쪽 분은 앞뒤, 오른쪽 분은 좌우를 맡아요. 두 팔을 들면 앞으로 가요.」 ⚠ 실제 자리(왼쪽·오른쪽)는 부스 배치를 보고 정함.

### 7-3 · 끄기

- 카메라 화면 창에서 **`q`**나 **`Esc`**를 누르면 꺼집니다.
- **노트북1(P1)을 끄면 차가 바로 섭니다.** 노트북2(P2)를 끄면 좌우만 멈춥니다.
- 끈 뒤 다시 켤 때는 「5」 → 「6」 순서로 켭니다(주소는 그대로면 다시 확인하지 않아도 됨).

## 부록 A · 블루투스 다시 잡기

**언제**: 노트북1에서 프로그램을 켰는데 차 불빛이 계속 깜빡일 때, 또는 `OUTPUT` 줄이 `COM3 OPEN`이 되지 않을 때.

### A-1 · 먼저 해 볼 것 (짝을 다시 맺지 않고)

1. 노트북1 프로그램을 끕니다(`q`).
2. **근처 다른 노트북(노트북2 포함)의 블루투스가 모두 꺼졌는지** 다시 봅니다. 가장 흔한 원인입니다(11/24~25).
3. 차 전원을 껐다가 켭니다. 건전지가 약하면 새것으로 바꿉니다.
4. 노트북1 프로그램을 다시 켭니다(「5」의 3번).

### A-2 · 짝을 다시 맺기

A-1로 안 되면 합니다. 짝을 다시 맺으면 **COM 번호가 바뀔 수 있으니** 새 번호를 확인해 명령에 넣습니다.

1. 노트북1에서 설정 → 블루투스 및 장치 → 장치에서 `IEUMCAR2`를 찾아 **장치 제거**합니다.
2. `Win + R`을 누르고 `DevicePairingWizard`를 입력해 Enter를 누릅니다(윈도우에 들어 있는 짝 맺기 창. 「장치 추가」로 맺으면 COM 포트가 안 생긴 적이 있습니다).
3. 목록에서 `IEUMCAR2`를 골라 짝을 맺습니다. ⚠ PIN을 물으면 팀원에게 따로 묻습니다(문서에 적지 않음).
4. 설정 → 블루투스 및 장치 → 장치 → 「추가 Bluetooth 설정」 → **「COM 포트」** 탭에서 `IEUMCAR2`의 **「송신(나가는)」** 포트 번호를 봅니다. 저절로 생긴 송신 포트를 씁니다(「추가」로 직접 만든 포트는 안 된 적이 있음).
5. 그 번호로 「5」의 명령에서 `COM3`을 바꿔 켭니다.

### A-3 · 지금까지 맺은 포트 번호 (11/25 기준)

| 노트북 | 메인 차 `IEUMCAR2` | 예비 차 `IEUMCAR1` |
|---|---|---|
| 노트북1(test1) | `COM3` | ⚠ 아직 짝 안 맺음 |
| 노트북2(test2) | `COM6` | `COM4` |
| my(sunbell 노트북) | `COM11` | `COM13` |

## 부록 B · 다른 노트북·다른 차로 바꾸기

### B-1 · 노트북1(P1)이 고장 났을 때 → 노트북2가 P1을 맡음

노트북2도 메인 차와 짝을 맺어 두었습니다(`COM6`). 노트북1의 블루투스를 끄고 노트북2를 P1으로 켭니다.

| 방법 | 노트북2 명령 | 시험 |
|---|---|---|
| ★ 두 사람: my를 P2로 붙임 | `.\run.bat --port COM6 --role P1 --listen --allow-from my주소` (my는 B-2의 P2 명령) | ⚠ 이 조합은 안 해 봄. 비슷한 조합(test2 = P1 + test1 = P2, 예비 차)은 11/24 통과 |
| 한 사람이 네 동작 모두(커브 안 됨) | `.\run.bat --port COM6 --letters ARMS_UP=W,T_POSE=S,LEFT_UP=A,RIGHT_UP=D` | 11/25 통과 |

### B-1-2 · 노트북2(P2)가 고장 났을 때

노트북1은 그대로 두고 my를 P2로 붙입니다(B-2). 노트북1의 `--allow-from` 자리를 my 주소로 바꿔 다시 켜야 합니다. 급하면 노트북1 혼자 네 동작으로 몹니다: `.\run.bat --port COM3 --letters ARMS_UP=W,T_POSE=S,LEFT_UP=A,RIGHT_UP=D`(11/25 통과).

### B-2 · my(sunbell 노트북)로 바꿀 때

my는 메인 차(`COM11`)와 예비 차(`COM13`) 모두 짝을 맺어 두었고, P1·P2 모두 시험을 통과했습니다(11/20·11/23·11/24).

| my가 맡을 역할 | 명령(`motion` 폴더에서) |
|---|---|
