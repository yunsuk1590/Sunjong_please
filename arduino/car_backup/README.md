# 예비 차 코드 (car_backup)

> **이 문서는?** 11/11(수) 학과 발표회에서 쓸, **노트북이 보낸 글자로 차를 움직이는 아두이노 코드의 예비판** 기록입니다.
> - **누가 읽나요?** 팀장 sunbell, 아두이노 담당 yunsuk1590.
> - **작성**: 2026-11-09, sunbell(Claude 도움).
> - **왜 예비판인가요?** 아두이노 담당은 yunsuk1590입니다. 담당자 코드가 발표회 전에 준비되지 못할 때를 대비해 sunbell이 따로 만들었습니다. 담당자 코드 자리(`arduino/car/`)는 비워 두었습니다.
> - 처음 보는 말은 맨 아래 「9 · 낱말 풀이」에 있습니다.

## 1 · 무엇을 하나

- 노트북이 보낸 **글자 하나**를 받아 차를 앞으로 보내거나 멈춥니다.
- **블루투스(HC-06)와 USB 선 양쪽**에서 같은 글자를 받습니다. 블루투스가 안 될 때 USB 선으로 바꿔 끼우면 됩니다.
- `F`를 받으면 **정해진 시간만 앞으로 가고 스스로 멈춥니다.** 노트북 프로그램이 멈추거나 연결이 끊겨도 차가 계속 달려 나가지 않습니다.
- 가는 도중에도 `S`를 받으면 바로 멈춥니다. 시간은 `delay()` 대신 `millis()`로 재서, 기다리는 동안에도 글자를 받습니다.
- 켜지면 멈춘 상태로 시작합니다.
- 받은 글자와 지금 상태를 USB 쪽(시리얼 모니터)에 글로 보여 줍니다.
- 키트 예제 코드는 옮기지 않고 **새로 썼습니다.** 배선(모터 단자, 블루투스 핀)만 키트 자료에서 확인했습니다.

## 2 · 글자 약속

| 글자 | 뜻 | 정한 날 · 정한 사람 |
|---|---|---|
| `F` (대문자) | 앞으로 | 2026-11-08 · sunbell |
| `S` (대문자) | 멈춤 | 2026-11-08 · sunbell |
| 그 밖의 글자, 줄바꿈(`\r`, `\n`) | 무시 | 2026-11-08 · sunbell |

- **대문자**만 알아듣습니다. 키트의 앱 조종 예제는 글자 뜻이 달라서(예: 소문자로 조종), 그 예제의 글자와 섞어 쓰지 않습니다.
- 글자를 바꾸려면 `car_backup.ino` 맨 위의 「글자 약속」만 고칩니다.

## 3 · 임시값 (아직 정하지 않은 것)

모두 `car_backup.ino` 맨 위에 상수(이름 붙인 고정값)로 모아 두었습니다. 정해지면 그 값만 바꿉니다.

| 이름 | 지금 값 | 뜻 | 누가 정하나 |
|---|---|---|---|
| `DRIVE_TIME_MS` | `1000` (1초) | `F` 하나에 앞으로 가는 시간 | sunbell과 yunsuk1590 |
| `RESTART_TIMER_ON_F` | `true` (시간 다시 재기) | 가는 도중 `F`가 또 오면: `true` = 그때부터 시간을 다시 잼(더 멀리 감), `false` = 무시 | sunbell과 yunsuk1590. 11/9 sunbell이 임시값으로 「다시 재기」를 골랐습니다 |
| `DRIVE_SPEED` | `200` (0~255) | 모터 속도. 왼쪽과 오른쪽이 같은 값 | 차에서 보고 정합니다. 지금 값은 Claude가 임시로 넣었습니다 |
| `LEFT_FORWARD_DIR`, `RIGHT_FORWARD_DIR` | `FORWARD` | 바퀴가 거꾸로 돌면 그 바퀴만 `BACKWARD`로 바꿉니다 | 차에서 확인 |

## 4 · 환경 (설치 버전과 보드 설정)

| 항목 | 내용 |
|---|---|
| 컴퓨터 | sunbell 윈도우 노트북 (발표회 시연용) |
| 아두이노 프로그램 | **Arduino IDE 2.3.10**. 터미널에서는 IDE 안에 들어 있는 `arduino-cli` 1.5.1을 씁니다 |
| 보드 설정 | Arduino AVR Boards **1.8.8**, 보드 **「Arduino Uno」**(`arduino:avr:uno`). 2026-11-03 팀이 차를 조립할 때 이 노트북에서 쓴 설정과 같습니다 |
| 모터 라이브러리 | **Adafruit Motor Shield library 1.0.1** (V1, 코드에서는 `AFMotor`). V2가 아닙니다. 각자 설치하고 레포에는 넣지 않습니다 |
| 블루투스 통신 | `SoftwareSerial` (아두이노 프로그램에 기본으로 들어 있음) |
| USB 칩 드라이버 | CH340용 드라이버가 이미 설치되어 있었습니다. 보드를 꽂으면 `COM9`로 보입니다 |
| 통신 속도 | USB, 블루투스 모두 **9600** (2026-11-08 sunbell 결정) |
| 컴파일 결과 (2026-11-09) | 프로그램 4,424바이트(13%), 전역 변수 316바이트(15%). 경고는 모터 라이브러리 안에서만 나왔습니다 |

## 5 · 배선

키트 자료 기준입니다. 조립한 차에서 확인한 결과는 「6 · 시험 방법과 결과」에 적습니다.

| 부품 | 연결 |
|---|---|
| 왼쪽 바퀴 | 모터 쉴드 **M1** |
| 오른쪽 바퀴 | 모터 쉴드 **M4** |
| HC-06 블루투스 | 아두이노가 받는 핀(RX) = **A5**, 보내는 핀(TX) = **A4** |

## 6 · 시험 방법과 결과

시험할 때는 시리얼 모니터를 **9600**으로 엽니다. 처음에는 차를 들어 올려 **바퀴를 띄우고** 합니다.

| 번호 · 시험 | 어떻게 | 됐다고 볼 때 | 결과 |
|---|---|---|---|
| 1 · 컴파일 | 보드 없이 `arduino-cli compile --fqbn arduino:avr:uno` | 오류 없이 끝남 | **통과** (2026-11-09) |
| 2 · 바퀴 띄우고 USB | USB 선으로 업로드하고 시리얼 모니터에서 글자를 보냄 | 켜자마자 멈춰 있음 / `F` → 두 바퀴가 앞으로 돌고 1초 뒤 스스로 멈춤 / `F` 뒤 바로 `S` → 바로 멈춤 / 가는 도중 `F` → 「시간 다시 잼」 / `f`, `x` → 무시 | 아직 |
| 3 · 바닥에서 USB | 2와 같고, 차를 바닥에 내려놓음 | 차가 앞으로 가다 1초 뒤 멈춤. 한쪽으로 크게 휘지 않음 | 아직 |
| 4 · 블루투스 | 노트북과 HC-06의 짝을 맺고, 「나가는(Outgoing)」 COM 포트를 시리얼 모니터로 열어 글자를 보냄 | 2·3과 같음 | 아직 |
| 5 · 몸 동작 프로그램과 이어 보기 | 노트북 몸 동작 프로그램을 블루투스 포트로 실행하고 두 팔을 듦 | 팔을 들면 차가 1초 가고 멈춤 / 프로그램을 끄면 멈춤 | 아직 |

## 7 · 쓸 때 주의

- **COM 포트는 한 번에 한 프로그램만** 열 수 있습니다. 노트북 몸 동작 프로그램을 켜기 전에 시리얼 모니터를 닫습니다. 업로드할 때도 시리얼 모니터를 닫습니다.
- 이 코드를 업로드하면 보드에 있던 프로그램(예: 키트 예제)은 지워집니다. 키트 예제가 다시 필요하면 다시 업로드합니다.
- USB 선으로 포트를 열면 보드가 다시 켜집니다. 짐작(아직 해 보지 않음): 포트를 연 직후 1~2초 안에 보낸 글자는 놓칠 수 있습니다.
- Claude 분석: 키트 자료에는 왼쪽과 오른쪽 모터 속도를 다르게 둔 예가 있습니다. 차가 한쪽으로 크게 휘면, 왼쪽과 오른쪽 속도를 따로 둘지 sunbell과 정합니다.

## 9 · 낱말 풀이

| 말 | 뜻 |
|---|---|
| 스케치 | 아두이노 프로그램 파일(`.ino`)입니다. 폴더 이름과 파일 이름이 같아야 합니다 |
| 상수 | 코드 맨 위에 이름을 붙여 둔 고정값입니다. 값을 바꾸려면 그 한 줄만 고칩니다 |
| `millis()` | 보드가 켜진 뒤 몇 ms(1/1000초)가 지났는지 알려 주는 함수입니다. 이것으로 시간을 재면 기다리는 동안에도 다른 일을 할 수 있습니다 |
| 시리얼 모니터 | 아두이노 프로그램 안의 창입니다. 보드와 글자를 주고받습니다 |
| COM 포트 | 윈도우에서 보드나 블루투스 모듈과 글자를 주고받는 통로의 이름입니다(예: `COM9`) |
| 업로드 | 컴파일한 프로그램을 보드에 넣는 것입니다 |
| 컴파일 | 사람이 쓴 코드를 보드가 알아듣는 형태로 바꾸는 것입니다 |
| HC-06 | 아두이노에 붙이는 블루투스 모듈입니다 |
| 짝 맺기(페어링) | 블루투스 기기끼리 처음 한 번 연결을 허락하는 것입니다 |
